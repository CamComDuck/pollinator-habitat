# Client Use of Software

Currently, the application is designed to display the clues about a random pollinator while following along a route as part of an activity to learn about pollinators. This is done using an API call and Typescript React. The client will allow activity participants to utilize this application instead of relying on paper materials. This also provides a platform for the activity to grow and reach new audiences. The application also contains an accessibility menu with high color contrast and text-to-speech options to include participants that have visual disabilties.
